# Physics Lab

포물선·진자/용수철·파동 수조 3종 실험대. 변수를 바꾸고 예측 vs 실측을 실시간 그래프로 비교하는 가상 물리 실험실입니다 (중2~고2).

- **정적 사이트**: 서버, 로그인, DB 없음.
- **런타임 AI 없음**: 빌드 후 LLM/API 호출 없음.

## 시작하기

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

자세한 학습 설계는 [`구현계획.md`](구현계획.md), 변경 기록은 [`docs/UPDATELOG.md`](docs/UPDATELOG.md) 참고.
